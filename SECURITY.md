# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

Please report security issues by opening a private security advisory on GitHub or
by emailing the maintainers directly. Include as much detail as possible:
steps to reproduce, affected versions, and any potential impact. You can expect
an initial response within 5 business days.
